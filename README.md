# Philippines Rice Production & Kubota Dealer Territorial Dashboard

Interactive Territorial Mapping & Agricultural Palay Heatmap for **Kubota Philippines Inc.** (PSA & PhilRice 2024–2026 Data).

## Overview
This repository contains interactive GIS dashboards designed for strategic planning, market analysis, and dealer network expansion for **Kubota NC Power Tillers** and agricultural machinery across all 82 provinces of the Philippines.

## Key Files
- **Rice Production Heatmap.html**: Complete interactive dashboard featuring:
  - **Choropleth Map**: 6-tier Agricultural Green scale for 82 provinces.
  - **Density Heatmap**: Smooth radial density layer.
  - **99 Kubota Authorized Dealers**: Interactive dots that expand on hover, featuring full dealer information (address, contacts, hours).
  - **Dealer Coverage Area**: Highlights 44 provinces with official dealer presence and identifies Opportunity Gaps.
  - **Kubota Strategic Insights**: Detailed field data for 15 priority rice-producing provinces (soil conditions, existing machinery, ADs, market penetration strategies).
- **Rice Production Area.html**: Initial strategic territory mapping dashboard for 15 key provinces.

## How to Run
Simply open Rice Production Heatmap.html in any modern web browser (Google Chrome, Microsoft Edge, Safari, Firefox). No web server or installation required.

## Data Sources
- **PSA (Philippine Statistics Authority)** - Official Palay Production Statistics
- **PhilRice (Philippine Rice Research Institute)**
- **Kubota Philippines Inc.** - Authorized Dealer Network
